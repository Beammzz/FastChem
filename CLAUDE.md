# CLAUDE.md

This project uses the **DOX framework** — a hierarchy of `AGENTS.md` files that act as binding
work contracts for their subtrees.

Read [`AGENTS.md`](./AGENTS.md) at the repository root first, then walk the DOX chain down to
every path you intend to touch and read each `AGENTS.md` along the way. Update the nearest
owning docs before considering a task done.

All project instructions live in the `AGENTS.md` tree. This file only points at it.
